# Changelog

## 0.1.0-preview.1 — 2026-10-15

First public Windows preview of the independent OpenVT Delta fork.

- Windows 11 x64 portable build with pinned, patched Godot and native extensions.
- Bundled OpenSeeFace 1.20.5 with a main-screen camera switch and tracking status.
- Standard Live2D head, eye, and mouth bindings when no custom mappings exist.
- Fixes for popout positioning, visible controls, metadata loading, and shutdown.
- Delta branding while preserving upstream copyright and dependency attribution.
- Third-party license notices and required corresponding source in the ZIP.
- Commit-identifiable executable names and removal of private native build paths.

The ZIP contains no avatar model or personal profile. Windows virtual-camera
output is not included; capture the application window with OBS.
